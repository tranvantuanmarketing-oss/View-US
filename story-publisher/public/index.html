Kết nối nhiều Page từ một tài khoản

Dùng User Access Token được cấp quyền quản lý Page. Publisher sẽ đọc danh sách, bạn chọn Page muốn thêm.

Token chỉ dùng để lấy danh sách. Phiên lựa chọn tự hết hạn sau 10 phút. Page Token của các Page được chọn được lưu mã hóa trên máy.

Cách lấy token & điều kiện quyền Meta
META / FACEBOOK

Kết nối đúng Page, đăng qua API

BM TikTok dùng cho TikTok. Đăng Facebook Reels cần Meta App và Page Access Token được cấp quyền cho Page của bạn.

  1. Tạo/cấu hình Meta App với khả năng quản lý Page.
  2. Cấp quyền đăng: pages_manage_posts, đọc Page: pages_read_engagement; liệt kê Page: pages_show_list.
  3. Đăng Comment 1 cần quyền pages_manage_engagement và quyền quản lý tương ứng. Quyền phụ thuộc theo cấu hình Meta App.
  4. Mở Graph API Explorer, chọn App của bạn, chọn User Token và cấp các quyền cần thiết. Dán User Token vào ô phía trên để đọc danh sách Page.
  5. Nếu đã có Page Access Token riêng, nhập ở Page & khung giờ. Có thể kiểm tra token bằng Token Debugger của Meta. Token hết hiệu lực cần kết nối lại.

Quyền truy cập ngoài các vai trò của App có thể cần App Review/Advanced Access. Kết nối đọc đúng Page chưa chứng minh quyền đăng; lần đăng thật đầu tiên mới xác minh toàn bộ luồng.

Chrome & Genlogin

Mở http://localhost:3030 trong Chrome hoặc profile Genlogin. Bạn chọn Page đã kết nối để đăng; phiên đăng nhập Facebook trong trình duyệt không thay thế Page Access Token.

Tiện ích một chạm nằm trong thư mục story-publisher/browser-extension. Chrome: Extensions → Developer mode → Load unpacked. Genlogin: Extensions → thêm tiện ích từ thư mục/ZIP theo bản bạn đang dùng.

Tiện ích chỉ mở Publisher. Chưa điều khiển/mở profile bằng API Genlogin; không đọc cookie hoặc mật khẩu Facebook.
