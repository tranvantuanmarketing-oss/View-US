## 🚀 2. CHECKLIST HÀNH ĐỘNG CỦA BẠN (HOÀN TẤT TRONG 5 PHÚT)

Vì việc tạo tài khoản trên `blogb.io` và `adsconex.com` yêu cầu nhận mã OTP xác thực qua Email/Số điện thoại cá nhân của bạn, các bước thực hiện rất đơn giản như sau:

1. **Bước 1 (1 phút):** Truy cập [https://blogb.io](https://blogb.io), đăng nhập hoặc đăng ký tài khoản bằng email của bạn.
2. **Bước 2 (2 phút):** 
   - Vào mục **My blog** ➔ Bấm tạo Website mới.
   - Nhập tiền tố subdomain bạn thích (ví dụ: `thesilenttruth` hoặc `fatefuldrama`).
   - Chọn đuôi miền `.cfx.bz` hoặc `.gigglelo.com`.
   - Chọn loại **Blog** ➔ Đặt Username và Mật khẩu cho trang web.
3. **Bước 3 (1 phút):** 
   - Vào [adsconex.com](https://adsconex.com) ➔ Chọn **Add new website** ➔ Điền tên web vừa tạo.
   - Copy **Code 1** dán vào ô **Script Head** trên trang quản trị web (`/login` ➔ Setting).
   - Copy **Code 2** dán vào ô **Ads.txt** trên trang quản trị web.
   - Kéo xuống bấm **Save**, sau đó sang Adsconex bấm **Verify**.
4. **Bước 4 (2 phút):** 
   - Vào menu **Blog ➔ Post ➔ Add New Blog**.
   - Copy lần lượt 5 bài viết mẫu đã được soạn sẵn đầy đủ tại thư mục:  
     `/Users/tony/Downloads/View US/adsconex/bai_viet_mau/`
5. **Bước 5 (30 giây):**
   - Nhắn tin cho bạn **Winni Adsconex** (hoặc gửi qua kênh hỗ trợ) với tin nhắn:  
     > *"Chào bạn, mình đã tạo web xong trên domain `https://[tên-subdomain-bạn-chọn]`, gắn đủ mã code Adsconex và đăng sẵn 5 bài content tiếng Anh chuẩn quy cách 1 câu 1 đoạn rồi nhé. Bạn kích hoạt set ads giúp mình nha!"*
